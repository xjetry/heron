# 多盘监控分离根盘容量与最满盘使用率

引入多挂载点本地磁盘采集后，`Metrics.disk_total` 与 `disk_used`（及其派生的历史 `disk_used` / `disk_used_pct`）继续固定代表根文件系统 `/`，而概览进度展示与磁盘资源告警改由新增的「最满盘使用率」（`disk_max_used_pct`）驱动，逐盘容量仅作为管理端实时快照下发。

若把多块本地盘的字节数求和填入 `disk_total` / `disk_used`，大容量的空闲数据盘（如 2 TiB `/data`）会把已写满 100% 的小根盘（如 20 GiB `/`）稀释成极低百分比导致漏报；反之若用最满盘直接覆盖 `disk_total` / `disk_used`，当两块盘的使用率交替领先时，`disk_used` 字节时序曲线会产生无物理意义的台阶跳变。分离两者既保持存量历史曲线连续，又在零动态子表膨胀的前提下守住单盘写满告警。
