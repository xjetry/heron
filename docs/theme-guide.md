# 公开页主题运维说明

主题是运行在浏览器中的静态前端，用于替换公开页的外观。管理员在 `/admin/` 的「主题」页安装、预览和启用，访客在同一域名的 `/` 查看；切换不改域名、不重启 hub。hub 只接收构建产物，不执行主题仓库里的构建脚本。

## 安装与升级

在后台填写 GitHub 仓库（`owner/repo`、仓库地址或指定 Release 地址），选择已发布 Release 的 ZIP 资产安装；也可以上传本地 ZIP。只支持公开仓库，不接受 GitHub 自动生成的源码压缩包；主题作者必须发布已经构建的产物。

GitHub 是安装来源，不是运行时依赖：下载校验后原包存入 hub，GitHub 不可用不影响已启用的版本。

- 安装新版本不覆盖当前版本，也不自动启用；可切回上一个版本或内置公开页。
- 最多安装 20 个主题，每个主题最多保留 3 个版本；超限时须显式清理，不会自动挤掉当前或回滚版本。
- 预览不改变全站选择；预览地址绑定管理员会话，不能当作公开分享链接。
- 主题管理需要管理员会话，API token 不可调用。

`--public-dir` 接管公开页时不能启用第三方主题，须先移除该参数并重启。

## 隔离与权限

- 主题页面在沙箱中运行：拿不到管理面板的会话与存储，不能注册 Service Worker，不能直接调用管理接口。
- 主题能读的公开数据经一组固定的只读方法提供，请求不带管理员凭据；其余请求被拒。
- 第三方脚本是主题作者供应链的一部分：沙箱隔离权限，不替作者担保页面内容。
- 公开页总闸同时约束内置页、主题与公开数据接口；关闭公开页不影响 `/admin/`，重新打开后保留原主题选择。

## 备份与恢复

配置快照保存全部保留版本、当前与回滚选择，以及原包清单；主题原包随快照一起上传到对象存储。

恢复前停止 hub，把快照引用的主题包下载到本地目录（按摘要命名的 `<SHA-256>.zip`）：

```sh
heron-hub restore --db heron.db --config config.db --themes ./theme-packages --yes
```

- 指定 `--themes` 时，快照要求的原包缺失或摘要不符会拒绝恢复。
- 省略 `--themes` 会恢复配置但清空主题文件与选择，管理员重新上传原包后再启用。
- 更新、清理或卸载本地主题不会删除历史快照引用的远端原包；远端主题对象不自动回收，需另行评估保留空间。
